# BLSV - B站音乐视频桌面端

基于 Electron + Vue 3 构建的 B站音乐视频播放器，支持歌单自动播放和桌面壁纸模式。

## 功能特性

- 歌单播放：支持外部歌单链接，自动在 B站 搜索并播放对应视频
- 播放模式：列表循环、单曲循环、随机播放
- 桌面壁纸：一键将播放器设为桌面壁纸
- 系统托盘：最小化后通过托盘控制播放
- 账号登录：支持 B站 账号登录，获取个性化内容
- 快捷键：空格播放/暂停、方向键调节音量和进度、F键全屏
- 毛玻璃 UI：现代化的半透明界面设计

## 技术栈

- Electron 31
- Vue 3
- Vite 5
- Element Plus

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（同时启动 Vite 和 Electron）
npm run dev

# 构建打包
npm run dist
```

## 使用说明

1. 首次启动会提示输入歌单链接（支持 QQ音乐、网易云音乐等平台）
2. 点击右上角用户头像可登录 B站 账号
3. 点击「桌面壁纸」按钮可切换壁纸模式
4. 底部控制栏支持播放、暂停、上下曲、音量调节和进度条拖拽
