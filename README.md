# BLSV - B站音乐视频桌面端

基于 Electron + Vue 3 构建的 B站音乐视频播放器，支持歌单自动播放和桌面壁纸模式。

## 功能特性

- **歌单播放**：支持 QQ音乐、网易云音乐等平台的歌单链接，自动在 B站 搜索并播放匹配视频
- **智能匹配**：根据歌名、歌手名对搜索结果打分排序，优先选择官方/MV/高清版本
- **播放模式**：列表循环、单曲循环、随机播放
- **桌面壁纸**：一键将播放器嵌入桌面壁纸（基于 `electron-as-wallpaper`）
- **系统托盘**：最小化后通过托盘控制播放、切歌、切换模式
- **账号登录**：支持 B站 账号登录，获取高清视频资源
- **快捷键**：
  - `空格` 播放/暂停
  - `↑↓` 调节音量
  - `←→` 调节进度（5秒）
  - `F` 全屏
  - `Esc` 退出全屏
- **毛玻璃 UI**：现代化半透明界面，自定义无边框标题栏
- **视频缓存**：搜索结果和视频地址本地缓存，减少重复请求
- **自动恢复**：Cookie 持久化存储，重启无需重新登录

## 技术栈

- [Electron](https://www.electronjs.org/) 42
- [Vue 3](https://vuejs.org/) 3.5
- [Vite](https://vitejs.dev/) 8
- [Element Plus](https://element-plus.org/) 2.14
- [electron-as-wallpaper](https://github.com/nicehash/electron-as-wallpaper) 2.0

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（同时启动 Vite 和 Electron）
npm run dev

# 壁纸模式开发（启动后直接嵌入桌面）
npm run wallDev

# 构建打包（NSIS 安装包 + 便携版 + MSI）
npm run dist
```

## 项目结构

```
├── electron/
│   ├── main.js           # Electron 主进程，窗口/托盘/壁纸管理
│   ├── preload.js         # 预加载脚本，暴露安全的 IPC 接口
│   ├── biliApi.js         # B站 API 封装（搜索/视频解析/用户信息/WBI签名）
│   ├── ipcHandlers.js     # IPC 事件处理器
│   └── cache.js           # 搜索结果本地缓存管理
├── src/
│   ├── App.vue            # 主界面（标题栏/播放器/控制栏）
│   ├── api/
│   │   └── electron.js    # 渲染进程 API 封装
│   └── components/
│       ├── biliVideoControls.vue  # 播放控制栏（进度条/音量/播放模式）
│       └── showList.vue           # 歌曲/视频列表弹窗
└── package.json
```

## 使用说明

1. 首次启动会提示输入歌单链接，粘贴 QQ音乐/网易云等平台的歌单分享链接即可
2. 点击右上角用户头像可登录 B站 账号，登录后可获取更高清的视频资源
3. 点击「桌面壁纸」按钮可将播放器嵌入桌面壁纸，再次点击恢复为普通窗口
4. 壁纸模式下登录窗口会显示 15 秒倒计时并自动关闭
5. 底部控制栏支持播放、暂停、上下曲、音量调节和进度条拖拽
6. 视频加载失败时自动跳过缓存重新请求
